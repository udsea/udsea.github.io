[PressureTrace](https://github.com/udsea/pressuretrace) is a research scaffold for studying pressure-induced transitions from robust problem solving toward shortcut-seeking or oversight-evasive behavior.

The project starts from reputable base datasets, then applies controlled transformations that preserve the task while introducing pressure conditions, oversight gaps, or shortcut opportunities. The current scope includes reasoning tasks inspired by GSM8K-style math, coding tasks inspired by HumanEval and MBPP, and a reasoning-family v2 path with frozen artifacts, probes, and first-pass route patching.

What this project is for:

- creating paired task variants with controlled pressure manipulations
- tracking behavioral traces instead of only final answers
- building artifacts for later probing and activation-patching analysis
- distinguishing robust task solving from shortcut-seeking under pressure

Status: active research scaffold. The reasoning-family path is more developed than the coding-family side.
